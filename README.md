# Создание персонажа в стиле ПЧК

Скилл для создания сказочных мультяшных персонажей в стиле ПЧК («Подземелья Чикен Карри») по описанию или референсу: характерные формы и пропорции, выразительные силуэты и мимика, тёмный контур, штриховка и мягкие цветные тени. Дизайн и рисовка закреплены приложенными визуальными образцами. По умолчанию — погрудный портрет с подходящим герою ракурсом, всегда размытый фон, без надписей и посторонних предметов.

Техническое имя скилла и репозитория — `dnd-character-art`; вызов `$dnd-character-art` сохраняется. Скилл создаёт иллюстрацию, а оформление игрового листа персонажа выполняется отдельно.

## Установка

Готовые файлы лежат в [релизах](https://github.com/Dezodemius/dnd-character-art/releases/latest).

| Где пользуетесь | Как подключить |
| --- | --- |
| **claude.ai**, Claude Desktop | Скачать [`dnd-character-art.zip`](https://github.com/Dezodemius/dnd-character-art/releases/latest/download/dnd-character-art.zip) → Настройки → Возможности → Skills → загрузить. В Desktop можно открыть [`dnd-character-art.skill`](https://github.com/Dezodemius/dnd-character-art/releases/latest/download/dnd-character-art.skill) двойным кликом |
| **Claude Code** | `/plugin marketplace add Dezodemius/agent-skills`, затем `/plugin install dnd-character-art@dezodemius-skills` |
| **Codex, Gemini CLI, Cursor, GitHub Copilot, OpenCode** и другие агенты | `npx skills add Dezodemius/dnd-character-art` |
| **ChatGPT, Gemini, DeepSeek, Qwen, Grok, Алиса, GigaChat** и другие чаты | Скачать [`dnd-character-art.prompt.md`](https://github.com/Dezodemius/dnd-character-art/releases/latest/download/dnd-character-art.prompt.md) и приложить в начале чата или вставить в инструкции проекта / GPT / Gem |

Подробно по каждой платформе — в [каталоге](https://github.com/Dezodemius/agent-skills#установка).

## Использование в агентах

1. Скачайте ZIP из Releases и распакуйте папку `dnd-character-art`.
2. Поместите её в каталог скиллов вашего агента либо подключите `SKILL.md` как инструкции вместе с `assets/`. Путь установки зависит от агента; поддержка одного формата импорта всеми продуктами не предполагается.
3. Попросите применить `dnd-character-art` и опишите персонажа. У агента должен быть доступ к изображениям в `assets/` и инструменту генерации с визуальными референсами.

Необязательный `agents/openai.yaml` содержит только метаданные интерфейса Codex. Основные инструкции от него не зависят.

Пример запроса:

> Примени dnd-character-art. Пожилая эльфийка-следопыт с короткими седыми волосами, шрамом на правой щеке и потёртым зелёным плащом. Взгляд в сторону, фон — осенний лес.

Можно задавать полный рост, другой кадр, ракурс, фон и собственный референс внешности. Фото задаёт узнаваемые черты, которые переводятся в мягкий портретный шарж; сохранённый образец — формы, степень преувеличения, контур и штриховку. Одежда и поза с фотографии переносятся, если это требуется запросом. Фон остаётся размытым.

## Использование на сайтах с ИИ

1. Распакуйте ZIP. Откройте `SKILL.md`, скопируйте текст после блока YAML между первыми двумя строками `---` в поле инструкций или сообщение генератору.
2. Загрузите главный утверждённый образец `assets/08-krista-approved.png`. Фото нового героя приложите отдельно как источник внешности; образец Кристы задаёт манеру рисунка. Дополнительные образцы используйте по необходимости.
3. Добавьте описание персонажа. Если сайт имеет разные поля, поместите образцы рисовки в style reference, а изображение героя — в character/identity reference.

Если сайт не умеет импортировать ZIP, используйте распакованные файлы. Если он принимает только текст, агент сможет подготовить промпт, но точность рисовки без визуальных образцов будет ниже. Этот архив содержит инструкции и референсы, а не модель или расширение для сайта.

## Состав архива

```text
dnd-character-art/
  SKILL.md
  agents/openai.yaml
  assets/01-satyr.png … assets/08-krista-approved.png
  references/midjourney.md
  LICENSE, NOTICE, VERSION, MANIFEST.json
```

В однофайловой версии `.prompt.md` картинок нет: для сайтов без импорта скиллов приложите
образцы из `assets/` отдельно (см. выше).

## Референсы

Главный ориентир — утверждённая пользователем иллюстрация Кристы: мягкий портретный шарж, выразительные формы, живой тёмный контур, заметная направленная штриховка и обобщённый цвет. Узнаваемость нового человека сохраняется через строение лица; внешность и костюм Кристы не копируются. Сохранённые параметры Midjourney: `--ar 25:31 --stylize 200 --weird 8`; ограничения воспроизведения описаны в `references/midjourney.md`.

Изображения предоставлены пользователем как образцы рисовки. Репозиторий не заявляет авторство или передачу прав на эти изображения; права принадлежат их правообладателям.
